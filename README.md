# Portfolio

Personal site of Umesh Chandra Tirumani: a story in five chapters that you fly through.

Live: https://umesh-chandra-2006.github.io/Portfolio/

## How it is built

- One file, `index.html`, with HTML, CSS and JavaScript inline. No build step.
- Three.js r128 from a CDN draws the 3D world. Without WebGL, or with reduced motion, the page falls back to a flat 2D starfield.
- Favicons, `site.webmanifest` and the resume PDF sit next to it.

## Run it

Open `index.html` in a browser.

## Deploy

GitHub Pages serves the `main` branch. Push and it updates.
