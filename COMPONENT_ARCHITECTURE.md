# 🏗️ Component Architecture Guide\n\n## File Structure\n\n```\nclient/src/\n├── components/\n│   ├── Layout/\n│   │   ├── Navbar.jsx        [Header with navigation + dynamic name]\n│   │   └── Footer.jsx        [Footer with dynamic social links]\n│   └── Sections/\n│       ├── Hero.jsx          [Landing section with CTA buttons]\n│       ├── About.jsx         [Bio + education details]\n│       ├── Projects.jsx      [Project cards with details]\n│       ├── Skills.jsx        [Skills organized by category]\n│       └── Contact.jsx       [Contact methods with icons]\n├── utils/\n│   └── api.js               [API helper functions]\n├── App.jsx                  [Main app component]\n├── main.jsx                 [React entry point]\n├── index.css                [Global styles]\n└── App.css                  [App-specific styles]\n```\n\n## Component Hierarchy\n\n```\nApp\n├── Navbar\n│   └── Navigation links (dynamic name from API)\n├── main\n│   ├── Hero\n│   │   └── Personal data (name, title, status)\n│   ├── About\n│   │   └── Education data (degree, university, coursework)\n│   ├── Skills\n│   │   └── Skills by category (with proficiency)\n│   ├── Projects\n│   │   ├── Project 1\n│   │   ├── Project 2\n│   │   └── Project 3\n│   └── Contact\n│       └── Contact methods with icons\n└── Footer\n    └── Social links (dynamic from API)\n```\n\n## Component LinkedIn, Email links\n\n---\n\n## API Integration Pattern\n\nAll components follow this pattern:\n\n```jsx\nimport { useEffect, useState } from 'react';\nimport { portfolioAPI } from '../../utils/api';\n\nconst MyComponent = () => {\n  const [data, setData] = useState(null);\n  const [loading, setLoading] = useState(true);\n\n  useEffect(() => {\n    const fetchData = async () => {\n      try {\n        const result = await portfolioAPI.getSomething();\n        setData(result);\n      } catch (error) {\n        console.error('Error:', error);\n      } finally {\n        setLoading(false);\n      }\n    };\n\n    fetchData();\n  }, []);\n\n  if (loading) return <LoadingSkeleton />;\n\n  return (\n    <section>\n      {/* Render data */}\n    </section>\n  );\n};\n\nexport default MyComponent;\n```\n\n## API Utility\n\n**File**: `client/src/utils/api.js`\n\n**Purpose**: Centralized API calls\n\n**Exports**: `portfolioAPI` object with methods:\n- `getPersonal()` - Get personal info\n- `getProjects()` - Get all projects\n- `getProject(id)` - Get single project\n- `getFeaturedProject()` - Get featured project\n- `getSkills()` - Get skills\n- `getEducation()` - Get education\n- `getCompletePortfolio()` - Get all data (for admin features)\n\n**Benefits**:\n- Centralized error handling\n- Easy to modify API URL\n- Consistent request/response format\n- Reusable across all components\n\n---\n\n## Data Flow\n\n### Single Component Data Fetch\n\n```\nComponent mounts\n      ↓\n    useEffect\n      ↓\n  portfolioAPI.getXXX()\n      ↓\n  HTTP request to backend\n      ↓\n  Backend reads JSON\n      ↓\n  Response sent to frontend\n      ↓\n  State updated with data\n      ↓\n  Component re-renders\n      ↓\n  User sees data\n```\n\n### Multiple Component Parallel Fetch\n\n```\nAbout component mounts\n      ↓\n    useEffect\n      ↓\n  Promise.all([\n    portfolioAPI.getPersonal(),\n    portfolioAPI.getEducation()\n  ])\n      ↓\n  Both requests in parallel\n      ↓\n  Both responses received\n      ↓\n  State updated\n      ↓\n  Component re-renders\n      ↓\n  Both sections displayed\n```\n\n---\n\n## Styling Strategy\n\n### Tailwind CSS Classes\n\nEach component uses consistent Tailwind patterns:\n\n```jsx\n// Container sizing\nclassName=\"max-w-7xl mx-auto\"\n\n// Responsive text\nclassName=\"text-lg md:text-xl lg:text-2xl\"\n\n// Responsive grid\nclassName=\"grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-8\"\n\n// Responsive padding\nclassName=\"px-4 sm:px-6 lg:px-8 py-12 md:py-20\"\n\n// Hover effects\nclassName=\"hover:bg-slate-50 hover:text-blue-600 transition-colors\"\n\n// Animations\nclassName=\"animate-pulse\" // loading skeleton\n```\n\n### Color System\n\n- **Primary**: Blue (blue-600, blue-50, blue-700)\n- **Background**: Slate (slate-50, slate-100, slate-900)\n- **Text**: Slate (slate-600, slate-900)\n- **Accents**: Gradient blues\n\n---\n\n## Performance Optimizations\n\n### Image Lazy Loading\n\n```jsx\n<img \n  src={project.visual} \n  alt={project.name}\n  loading=\"lazy\"\n/>\n```\n\n### Conditional Rendering\n\n```jsx\n// Only render if data exists\n{personal?.resumeLink && (\n  <a href={personal.resumeLink}>\n    Download Resume\n  </a>\n)}\n```\n\n### Parallel Data Fetching\n\n```jsx\nconst [personal, projects, skills] = await Promise.all([\n  portfolioAPI.getPersonal(),\n  portfolioAPI.getProjects(),\n  portfolioAPI.getSkills()\n]);\n```\n\n---\n\n## Adding New Components\n\n### Template\n\n```jsx\nimport { useEffect, useState } from 'react';\nimport { portfolioAPI } from '../../utils/api';\n\nconst NewComponent = () => {\n  const [data, setData] = useState(null);\n  const [loading, setLoading] = useState(true);\n\n  useEffect(() => {\n    const fetchData = async () => {\n      try {\n        const response = await portfolioAPI.getNewData();\n        setData(response);\n      } catch (error) {\n        console.error('Error fetching data:', error);\n      } finally {\n        setLoading(false);\n      }\n    };\n\n    fetchData();\n  }, []);\n\n  if (loading) {\n    return (\n      <section className=\"py-20\">\n        <div className=\"animate-pulse\">Loading...</div>\n      </section>\n    );\n  }\n\n  return (\n    <section className=\"py-20 px-4 sm:px-6 lg:px-8 max-w-7xl mx-auto\">\n      {/* Your component JSX */}\n    </section>\n  );\n};\n\nexport default NewComponent;\n```\n\n### Steps\n\n1. Create file in appropriate folder\n2. Add state for data and loading\n3. Add useEffect to fetch data\n4. Add loading skeleton\n5. Add JSX to render data\n6. Import in App.jsx\n7. Add to App.jsx render\n8. Add navigation link in Navbar\n9. Style with Tailwind\n10. Test in browser\n\n---\n\n## Common Patterns\n\n### Loading Skeleton\n\n```jsx\nif (loading) {\n  return (\n    <div className=\"animate-pulse\">\n      <div className=\"h-8 bg-slate-200 rounded w-1/4 mb-6\"></div>\n      <div className=\"space-y-2\">\n        <div className=\"h-4 bg-slate-200 rounded\"></div>\n        <div className=\"h-4 bg-slate-200 rounded w-5/6\"></div>\n      </div>\n    </div>\n  );\n}\n```\n\n### Optional Rendering\n\n```jsx\n{data?.optional_field && (\n  <div>\n    {data.optional_field}\n  </div>\n)}\n```\n\n### Conditional Styling\n\n```jsx\n<div className={`text-lg ${\n  isFeatured ? 'text-blue-600 font-bold' : 'text-slate-600'\n}`}>\n  {text}\n</div>\n```\n\n### External Links\n\n```jsx\n<a \n  href={url}\n  target=\"_blank\"\n  rel=\"noopener noreferrer\"\n>\n  Link Text\n</a>\n```\n\n---\n\n## Testing Components Locally\n\n### Check Component Rendering\n\n1. Open DevTools → Device Toolbar (Ctrl+Shift+M)\n2. Test iPhone SE (375px)\n3. Test iPad (768px)\n4. Test Desktop (1920px)\n5.
